## 何が起きているのか

まず見てほしいのはこれ。同じ超立方体を、設定を 1 つ変えて撮った 2 枚だ。

![超立方体、ほぼ平行投影](/images/nth/hypercube-d5.jpg)
*ランプを遠くに置いたとき。教科書で見る「立方体の中に立方体」*

![超立方体、裏返る瞬間](/images/nth/hypercube-d1.jpg)
*ランプを近づけたとき。内側にあった小さな立方体が膨らんで、画面の外へ抜けていく*

3 次元の立方体をどう回しても、内側の面が外側に来ることはない。ところが 4 次元で回すと、さっきまで奥にあった小さな部屋が手前に膨らんできて、画面全体を覆い、そのまま外へ抜けていく。「4 次元を見る」というのは、この裏返りを見ることだと思っている。

この記事は、それを起こしている仕組みの話。結論から言うと、頂点シェーダーの 4 行で済む。

## 地球儀を 1 次元上げる

地球儀は 3 次元の球面で、それを紙（2 次元）に描くのが地図投影だ。その中に「立体射影」という方法がある。北極にランプを置いて、球面上の各点の影を平面に落とす。

- 円は円のまま写る（形が壊れない）
- ランプに近い点ほど影が遠くへ飛び、北極そのものは無限遠に行く

4 次元でも同じことができる。4 次元空間の中の「3 次元の球面」（座標は x, y, z, w の 4 つ、原点からの距離が 1 の点の集まり）の上に図形を置き、w 軸の上にランプを置いて、影を普通の 3 次元空間に落とす。あとは普通のカメラで見ればいい。

超立方体や 120 胞体のような正多胞体は、もともと頂点がこの球面の上に乗るように作れるので、相性がいい。

## シェーダーの 4 行

頂点ごとにやることはこれだけ。`matrix4d` が 4×4 の回転行列、`distance` がランプの高さ d。

```ts
const rotated = matrix4d.mul(vec4(positionLocal, positionW)); // 4D 回転
const onSphere = normalize(rotated);                          // 球面に乗せ直す
const scale = distance.div(distance.sub(onSphere.w));         // d / (d − w)
return onSphere.xyz.mul(scale);                               // 3D の位置
```

3 行目が射影の本体。点の `w` が `d` に近づくと分母がゼロに近づき、その点は無限遠へ飛ぶ。図形が回転して一部がランプに近づくたびに、画面では裏返って見える。上の 2 枚目の写真は、まさに 1 つの胞がランプを通り抜けている瞬間だ。

ランプの高さ d はスライダーにしてある。1 に近いほど激しく裏返り、大きくするとランプが遠ざかって平行投影に近づき、1 枚目のようなおとなしい 3D モデルになる。

## 直線が曲線になるので、辺を分割する

写真の辺はどれも曲がっている。立体射影は直線を円弧に写すからだ。

ただし GPU は、渡された頂点の間を直線で結ぶだけなので、辺の両端だけ渡しても直線のままになる。そこで各辺を 8〜60 個に分割してから GPU に渡し、分割点の 4 次元座標を補間させる。すると曲がりは勝手に現れる。分割数は見た目で決めた。超立方体は 40、辺が長い五胞体は 60。

## 4 次元の回転には軸がない

3 次元の回転は「軸のまわり」で回る。4 次元には回転軸というものがなく、回転は「平面の中」で起きる。平面は xy, xz, yz, xw, yw, zw の 6 つあり、それぞれ独立に回せる。

実装は、6 つの平面それぞれに角速度を持たせ、毎フレーム 6 つの回転行列を掛け合わせて 4×4 行列を組み直すだけ。前フレームの行列に差分を掛け続けると誤差で少しずつ歪んでいくが、毎回ゼロから組み直せば常に厳密な回転になる。テストは「500 フレーム回しても直交行列で行列式が 1」で固定した。

冒頭の裏返りは、この 6 つのうち w が絡む 3 つ（xw, yw, zw）が起こしている。図形の一部をランプに近づけたり遠ざけたりするのがこの 3 平面だからだ。

## まとめ

- 4 次元の可視化は「回転 → 球面に正規化 → ランプから透視投影」の 4 行
- 裏返って見えるのは、点がランプを通り抜けるから
- 曲がって見えるのは、辺を分割しているから
- 4 次元の回転は 6 平面、毎フレーム行列を組み直す
